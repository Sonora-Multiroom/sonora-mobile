## Issues found

None in the app.

**Test incident (run procedure, fixed in the script).** Do Not Disturb was not on. During S8 an
Instagram message notification dropped over the app, and an adb tap meant for the link field opened
an Instagram chat. The keystrokes of that step (45 × Backspace, a link, Enter, a space) went to
Instagram's message field; the screenshot afterwards showed the field empty and no new message. The
run stopped, the user was told, Do Not Disturb was set to total silence, and every input from then on
checked that Sonora was in front. [full-app-test.md](../full-app-test.md) now has both steps (P3 and
"How to run it") and restores the mode in teardown.

Observations, not defects:

- Now Playing's status line ellipsizes a group with long room names ("on Living Room · Office
  Speaker + Kitchen Sp…"). Rooms cards do the same. Readable, but the last member is cut.
- The file sample (`oceanwavescrushing`) ends after ~2 min and the hub removes its route; start it
  just before the rows that need it.
- `POST /play` answered 200 for a link (not 201); the app handles both.
